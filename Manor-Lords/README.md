# Manor Lords - Vietnamese Localization Mod Project

Dự án bản địa hóa / Việt hóa cho game **Manor Lords** (Unreal Engine 5.5).

## Cấu trúc thư mục:
- `tools/`: Các công cụ trích xuất và đóng gói (repak, DataTable converter)
- `extracted/`: File gốc UAsset trích xuất từ game
- `translations/`: File JSON/CSV chứa các chuỗi văn bản tiếng Việt
- `build/`: Thư mục staging cho bản build Mod
- `dist/`: File ZIP/PAK thành phẩm để phát hành
