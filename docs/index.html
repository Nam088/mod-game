HƯỚNG DẪN CÀI ĐẶT 3 BƯỚC

Cài đặt gói mod ngôn ngữ nhanh chóng vào game bản quyền của bạn.

1

Tải File Mod ZIP

Nhấp vào nút Tải Mod ZIP của tựa game bạn đang sở hữu để tải gói ngôn ngữ Tiếng Việt từ GitHub Release.

2

Giải Nén Vào Game

Giải nén file ZIP vào thư mục Mods của game bản quyền theo hướng dẫn cụ thể trong bảng chi tiết.

3

Chọn Tiếng Việt

Khởi động game bản quyền, vào menu Cài đặt (Settings) ➔ Ngôn ngữ (Language) ➔ Chọn Tiếng Việt và trải nghiệm!

CÂU HỎI THƯỜNG GẶP

Giải đáp thắc mắc về tính pháp lý, font chữ và cách cập nhật mod.

1. Trang web này có chia sẻ game lậu hay bản crack không?
TUYỆT ĐỐI KHÔNG. Chúng tôi chỉ chia sẻ các tệp tin mod ngôn ngữ (file CSV, file PAK bản dịch, manifest mod) do nhóm biên dịch thực hiện. Để sử dụng mod, người chơi cần sở hữu bản game có bản quyền trên Steam, Epic Games hoặc GOG.
2. Các bản mod ngôn ngữ này có an toàn và miễn phí không?
Hoàn toàn 100% An Toàn và Miễn Phí. Toàn bộ file mod đều là các tệp văn bản/dữ liệu ngôn ngữ và mã nguồn mở công khai trên GitHub, không chứa mã độc, không can thiệp vào file thực thi của game.
3. Bản mod có bị lỗi font hoặc lỗi ô vuông tiếng Việt không?
Hoàn toàn không. Mỗi bản mod đều được tích hợp bộ font Unicode tiếng Việt chuẩn (Manor Lords, Against The Storm, Going Medieval, Timberborn...), đảm bảo hiển thị sắc nét 100% không lỗi dấu.
